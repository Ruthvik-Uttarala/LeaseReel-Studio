# LeaseReel Studio

Static React/Vite landing page for LeaseReel Studio, a founder-led rental-property media production offer.

## Local Setup

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually `http://localhost:5173`.

## Checks

```bash
npm run check
npm run test:e2e
npm run build
```

## Deployment Target

Cloudflare Pages:

- Project name: `leasereel-studio`
- Build command: `npm run build`
- Output directory: `dist`
- Canonical URL: `https://www.leasereelstudio.com/`

See `DEPLOY.md` for the launch runbook.
