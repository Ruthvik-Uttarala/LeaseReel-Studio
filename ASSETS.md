# Demo Assets

Place final demo media here:

- `public/media/demo-reel.mp4`
- `public/media/demo-reel-poster.webp`
- `public/media/demo-story.mp4`
- `public/media/demo-story-poster.webp`
- `public/media/demo-web.mp4`
- `public/media/demo-web-poster.webp`

After adding all files, set `assetsReady: true` in `src/content/site.ts`.

## Recommended Specs

- Social Reel: MP4, H.264, 1080x1920, 20-30 seconds, muted-safe captions, target 6-10 MB.
- Story / Ad Cut: MP4, H.264, 1080x1920, 8-12 seconds, target 3-6 MB.
- Website Video: MP4, H.264, 1920x1080, 15-30 seconds, target 6-12 MB.
- Posters: WebP, same aspect ratio as each video, target 80-180 KB.

Do not scrape property-manager websites. Use only licensed presentation imagery or photos the property owner or manager authorizes LeaseReel Studio to use and process.

The current site displays an “Interactive concept preview” fallback until real MP4 and poster assets are supplied.
